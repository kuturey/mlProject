# Оценка стоимости недвижимости

![Python](https://img.shields.io/badge/Python-3.12-blue)
![Django](https://img.shields.io/badge/Django-6.0.2-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

Веб-приложение для оценки стоимости недвижимости с использованием машинного обучения. Проект разработан на Django и позволяет пользователям вводить характеристики объекта недвижимости и получать предсказанную стоимость.
