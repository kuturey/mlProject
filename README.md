## 📖 О проекте

Этот проект создан для демонстрации работы модели машинного обучения в веб-интерфейсе. Пользователь может ввести параметры недвижимости:

- тип объекта
- площадь
- количество комнат
- этаж
- местоположение
- и другие характеристики

и получить предсказанную рыночную стоимость.

## 🚀 Установка и запуск

### Предварительные требования

- **Python** 3.8 или выше
- **pip** (менеджер пакетов)
- **Git**

### Пошаговая установка

#### 1. Клонируйте репозиторий

```bash
git clone https://github.com/kuturey/property-evaluation.git
cd property-evaluation
```

#### 2. Создайте виртуальное окружение

```bash
python -m venv .venv
```

#### 3. Активируйте виртуальное окружение

**Для Windows:**
```bash
.venv\Scripts\activate
```

**Для macOS/Linux:**
```bash
source .venv/bin/activate
```

*После активации в начале строки терминала появится `(.venv)`*

#### 4. Установите зависимости

```bash
pip install -r requirements.txt
```

#### 5. Примените миграции

```bash
python manage.py migrate
```

#### 6. Запустите сервер

```bash
python manage.py runserver
```

#### 7. Откройте в браузере

Перейдите по адресу: **http://127.0.0.1:8000/**

## 🎯 Использование

### Как пользоваться сайтом:

#### 1. Главная страница
- Нажмите кнопку **"Начать оценку"**

#### 2. Заполнение формы
- **Тип недвижимости:** квартира, дом, коммерческая
- **Площадь:** общая, жилая, кухни
- **Количество комнат**
- **Этаж** и **общее количество этажей**
- **Год постройки** (необязательно)
- **Город**, **район** (необязательно), **улица** (необязательно)
- **Состояние** объекта
- **Дополнительно:** балкон, парковка
- **Расстояние до метро** (необязательно)

#### 3. Получение результата
- Нажмите кнопку **"Оценить"**
- Просмотрите предсказанную стоимость и характеристики
